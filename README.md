# GamePilot

<img src="gamepilot/assets/gamepilot.png" width="80" alt="GamePilot icon">

**1.0.0 beta · 鸣潮周常乐园助手 · Windows / Python 3.11**

面向周常乐园的截图识别与页面状态机工具，提供图像模板、Windows OCR、目标红框、窗口绑定、暂停与 F8 紧急停止。

## 使用

1. 安装 Python 3.11，执行 `python -m pip install -r requirements.txt`。
2. 执行 `python gamepilot/main.py`，按系统 UAC 提示操作。脚本权限应与游戏匹配。
3. 在“识别设置”中自动定位游戏，保存截图区域。
4. 点击“开始自动执行”。程序从当前页面识别，控制窗口最小化到任务栏。
5. 恢复窗口会暂停；F8 紧急停止。“仅识别预览”不提交输入。

Windows OCR 依赖系统已安装的相应识别语言；首次启动不下载模型。请保持游戏画面可见。

检测等待间隔默认为 50ms；OCR、匹配与游戏动画耗时另计，不是每 50ms 固定点击。目标须经连续确认、窗口/遮挡检查及点击前复核，点击后验证页面变化。

## 页面流程

- P1：阶段确认；P2：进入下一天；P3：跳过；P4：进入新阶段；P5：关闭商店。
- 阶段2按已确认流程处理：P1确认 → P5关闭 → P2右上角退出 → 暂停菜单重新开始 → 验证阶段1。
- 未知画面、遮挡、窗口位置变化或验证失败时暂停。

## 检查与构建

```powershell
python -m unittest discover -s gamepilot/tests -v
python -m pip install -r requirements-dev.txt
python tools/build_exe.py
```

构建输出为 `dist/GamePilot.exe`。图标、模板、OCR 脚本及版本属性会一并打包。配置与日志生成在程序旁的 configs、reports 中，不写入仓库。

公开仓库排除了完整游戏截图与实机截图，以避免公开用户标识；依赖这些私有素材的测试会明确跳过。保留的模板为所需界面局部裁剪，不包含完整实机报告。

本地开发曾完成138项回归、六图识别、GUI最小化/恢复及9步完整GUI工作线程离线流程检查。离线流程使用参考画面和无输入记录器，不能当作实机刷关证据。使用者曾反馈修复基线可运行；跨电脑、不同分辨率、正常UAC交互及长时间运行仍需继续验证。
